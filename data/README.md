# Data Directory

This directory should contain the following three datasets:

1. `Inter-StateWarData_v4.0.csv` — COW Inter-State War Data v4.0
2. `NMC_Data_v6.0.csv` — COW National Material Capabilities v6.0
3. `V-Dem-CY-Core-v12.csv` — V-Dem v12 Country-Year Core Dataset

Due to licensing, these datasets are not included in the repository. Please download 
them from the official sources listed in the main README.md.
